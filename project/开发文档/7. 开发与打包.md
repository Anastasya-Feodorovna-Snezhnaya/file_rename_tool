# 7. 开发与打包

以下命令均假定当前终端位于仓库根目录；先进入项目目录：

```bash
cd project
```

## 7.1 运行

```bash
python main.py
```

运行时依赖 Python 标准库和可用的 Tkinter 安装。

## 7.2 测试

```bash
python -m unittest discover -s tests -v
```

核心测试应覆盖文件名排序、编号位数、序列数字排序、插入位置、扩展名保留、目标冲突和两阶段重命名回滚。配置管理的测试还应覆盖旧版配置缺少新增字段时的默认值兼容，以及窗口尺寸和目录偏好的保存/读取。

## 7.3 打包

```bash
python -m pip install -r requirements.txt
pyinstaller --noconsole --onefile --name 批量文件重命名工具 main.py
```

EXE 运行时配置和日志位置由进程当前工作目录决定。若通过快捷方式启动，可在快捷方式属性中设置“起始位置”。开发时从 `project/` 目录启动，可使配置和日志文件也留在该目录，并由 `.gitignore` 忽略。

## 7.4 GUI 偏好设置

`settings.json` 兼容旧版编号设置，并新增主窗口几何信息、预览窗口几何信息、普通重命名目标目录和序列插入目标目录。关闭主窗口时保存主窗口尺寸/位置及两个目录；关闭预览窗口时保存预览窗口尺寸/位置。

预览组件根据文件名长度估算双列宽度，但初始和最大窗口宽度不超过屏幕宽度的一半。超长文件名通过水平滚动条查看；用户可在该限制范围内手动拉伸预览窗口。
