# 7. 开发与打包

以下命令均假定当前终端位于仓库根目录。

## 7.1 运行

```bash
python project/main.py
```

运行时依赖 Python 标准库和可用的 Tkinter 安装。

## 7.2 测试

```bash
python -m unittest discover -s project/tests -v
```

核心测试应覆盖文件名排序、编号位数、序列数字排序、插入位置、扩展名保留、目标冲突和两阶段重命名回滚。

## 7.3 打包

```bash
python -m pip install -r project/requirements.txt
pyinstaller --noconsole --onefile --name 批量文件重命名工具 project/main.py
```

EXE 运行时配置和日志位置由进程当前工作目录决定。若通过快捷方式启动，可在快捷方式属性中设置“起始位置”。
