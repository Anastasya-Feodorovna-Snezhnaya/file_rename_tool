# 3. 项目结构

仓库根目录只保留面向使用者的 `README.md` 和集中存放项目文件的 `project/` 目录。应用代码、测试、依赖声明、Git 忽略规则和开发文档均位于 `project/` 内。

```text
file_rename_tool/
├── README.md
└── project/
    ├── .gitignore
    ├── main.py
    ├── requirements.txt
    ├── src/
    │   ├── core/
    │   │   ├── file_scanner.py
    │   │   ├── rename_rules.py
    │   │   ├── rename_engine.py
    │   │   └── sequence_insert.py
    │   ├── gui/
    │   │   ├── main_window.py
    │   │   ├── batch_rename.py
    │   │   ├── sequence_insert.py
    │   │   └── preview_dialog.py
    │   └── utils/
    │       ├── config.py
    │       └── logger.py
    ├── tests/
    │   └── test_core.py
    └── 开发文档/
        ├── 1. 项目概述.md
        ├── 2. 功能需求.md
        ├── 3. 项目结构.md
        ├── 4. 核心模块设计.md
        ├── 5. 文件重命名安全机制.md
        ├── 6. 配置与日志.md
        └── 7. 开发与打包.md
```

## 职责边界

- 仓库根目录的 `README.md`：用户使用说明、运行方式和 EXE 打包入口说明。
- `project/main.py`：程序入口。
- `project/src/core`：扫描、排序、命名规则、计划构建和文件系统重命名；不得依赖 GUI。
- `project/src/gui`：Tkinter 界面、输入收集、预览展示和用户确认。
  - `batch_rename.py`：普通批量重命名界面。
  - `sequence_insert.py`：文件序列插入界面。
  - `preview_dialog.py`：可调整大小的双列重命名预览窗口。
  - `main_window.py`：主窗口、编号设置和窗口/目录偏好保存。
- `project/src/utils`：配置读写和日志初始化。
- `project/tests`：核心逻辑的自动化测试。
- `project/requirements.txt`：项目运行/打包依赖声明。
- `project/.gitignore`：忽略 Python 缓存、IDE 文件、运行配置/日志和打包产物。
- `project/开发文档`：需求、结构、设计和维护说明。

## 路径与启动约定

从仓库根目录进入 `project/` 后，使用 `python main.py` 启动。测试和打包命令也建议在 `project/` 目录内执行。这样，进程当前工作目录为 `project/`，运行时生成的配置和日志文件也位于该目录，并由 `project/.gitignore` 忽略。若从其他工作目录启动，配置和日志仍会写入实际的进程当前工作目录。
