# 6. 配置与日志

## 6.1 路径约定

通过 `Path.cwd()` 获取进程当前工作目录：

- 配置文件：`settings.json`
- 日志文件：`rename_tool.log`

当前工作目录是进程启动时继承或由启动环境指定的工作目录，不等同于 Python 脚本目录或 EXE 所在目录。

## 6.2 配置内容

配置文件保存以下内容：

- 编号位数模式：`mode`；
- 固定额外位数：`extra_digits`；
- 自动阈值：`threshold_percent`；
- 主窗口尺寸和位置：`window_geometry`；
- 重命名预览窗口尺寸和位置：`preview_geometry`；
- 普通批量重命名目标目录：`batch_directory`；
- 文件序列插入目标目录：`sequence_directory`。

窗口几何信息使用 Tkinter 的 geometry 字符串格式保存，例如 `900x700+100+80`。配置缺少新增字段时采用默认值，因此旧配置文件仍可读取。主窗口尺寸和两个目标目录在主窗口关闭时保存；预览窗口尺寸在预览窗口关闭时保存。

配置文件损坏或字段无效时记录日志并使用默认配置。写入异常会记录日志并向调用方抛出。

## 6.3 日志

日志包含时间、级别、模块和消息。GUI 捕获异常后向用户显示简明错误，同时将堆栈信息写入日志。
