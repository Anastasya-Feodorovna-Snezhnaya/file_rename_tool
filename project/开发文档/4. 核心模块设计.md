# 4. 核心模块设计

## 4.1 文件扫描

普通批量重命名支持指定扩展名或 `*` 全部文件。排序键由文件名主体、扩展名和完整文件名组成；文件名主体通过 `os.path.splitext` 去掉最后一个扩展名获得。

序列扫描使用前缀和尾部格式构建匹配规则，扩展名不参与序号提取。序列按数字序号排序，而不是按字符串排序，避免 `(10)` 排在 `(2)` 前面。

## 4.2 命名规则

尾部格式必须且仅包含一个小写 `n`。生成名称时根据总文件数和编号设置计算填充宽度，再将 `n` 替换为零填充后的序号。源文件扩展名作为独立部分追加到目标名称。

## 4.3 计划与执行分离

计划生成阶段只产生源路径、目标路径和预览数据，不修改文件系统。执行阶段再次检查源文件和目标路径，然后调用安全重命名引擎。

GUI 在用户确认前展示完整计划；确认后重新扫描并重建计划，避免目录内容变化导致使用过期数据。
