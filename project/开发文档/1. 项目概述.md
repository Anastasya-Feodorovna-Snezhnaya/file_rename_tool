# 1. 项目概述

## 1.1 项目目标

提供一个 Windows 桌面批量文件重命名工具，保留原有的普通批量重命名能力，并增加两组文件序列的有序插入能力。

## 1.2 设计原则

- 保留旧版核心操作：目录选择、扩展名筛选、前缀、尾部格式、起始序号、刷新、清空和预览确认。
- GUI 与文件处理逻辑分离；文件扫描、命名规则、计划生成和重命名执行不依赖 Tkinter。
- 所有重命名操作先生成计划并进行冲突检查，再执行。
- 混合扩展名作为合法输入；目标文件名保留每个源文件的原始扩展名。
- 配置和日志写入进程当前工作目录，而不是假定写入 EXE 所在目录。
- 发生异常时给出 GUI 错误提示，并记录详细日志。

## 1.3 主要功能

1. 普通批量重命名。
2. 两组文件序列的有序插入与统一重新编号。
3. 可配置编号位数。
4. 预览、冲突检查、两阶段重命名和失败回滚。
