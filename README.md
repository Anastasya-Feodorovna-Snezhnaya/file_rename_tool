# 批量文件重命名工具

一个基于 Python 和 Tkinter 的桌面工具，支持普通批量重命名，以及将一组连续编号的文件插入另一组文件序列。

## 功能

- 普通批量重命名：按文件名排序后，依据前缀、尾部格式和起始序号生成新文件名。
- 文件序列插入：将第二组序列插入第一组指定位置，并对合并后的序列重新编号。
- 支持混合扩展名；每个文件保留自己的原始扩展名。
- 普通批量重命名可按扩展名筛选，也可选择全部扩展名。
- 支持固定增加编号位数和按容量阈值自动增加编号位数。
- 执行前显示可调整大小的双列预览；预览列宽按文件名长度估算，并受屏幕宽度一半的上限约束，必要时可手动调整窗口或使用水平滚动条。
- 文件列表为只读文本，可用鼠标拖选文本并复制。
- 窗口尺寸、预览窗口尺寸和两种操作各自的目标目录会保存到配置文件。

## 环境要求

- Python 3.10 或更高版本
- Tkinter（通常随 Python 安装提供）

## 运行

在终端中进入 `project/` 目录后执行：

```bash
cd project
python main.py
```

## 使用说明

### 普通批量重命名

1. 选择目标目录。
2. 输入扩展名筛选条件，例如 `.png`；输入 `*` 表示包含所有扩展名。
3. 在独立的一行中输入新文件名前缀；尾部格式和起始序号在下一行设置。
4. 刷新文件列表，检查排序结果。文件列表支持鼠标拖选和复制，但不能直接编辑。
5. 点击开始处理，在可调整大小的预览窗口中检查原文件名和新文件名，再确认执行。

尾部格式必须且仅包含一个小写字母 `n`，例如 `(n)`、`n`、`_{n}`。生成文件名时，`n` 会被替换为编号。

### 文件序列插入

1. 选择包含两组文件序列的目录。
2. 分别在独立的一行中输入第一组和第二组的文件名前缀。
3. 输入两组文件共同使用的尾部格式，例如 `(n)`。
4. 设置插入位置：输入 `3` 表示插入到第一组第 3 个文件之后；输入 `0` 表示插入到第一组之前。
5. 设置起始序号，并在独立的一行中输入合并后使用的新前缀。
6. 在可调整大小的预览窗口中检查结果并确认。

序列文件名的匹配形式为“前缀 + 尾部格式（其中 n 对应数字）+ 可选扩展名”。扩展名不参与序列匹配和编号排序，并在输出时原样保留。

### 预览窗口

预览表格根据原文件名和新文件名的长度估算初始列宽，预览窗口初始宽度不超过屏幕宽度的一半。可以拖动窗口边缘调整大小；如果文件名仍超出可视区域，可使用表格底部的水平滚动条。预览窗口的尺寸会在关闭时保存。

## 编号位数

编号位数设置作用于两种重命名操作：

- **固定增加位数**：基础位数为表示总文件数所需的最少十进制位数，再额外增加 0～5 位。比如总数为 11、额外增加 1 位，则编号为 `001`～`011`。
- **按容量阈值自动增加位数**：先计算基础位数，再计算“总文件数 / 10 的基础位数次方”。只有该比例严格大于阈值时，才额外增加一位。阈值范围为 0～100%。

设置保存在当前工作目录的 `settings.json` 中。

## 配置和日志位置

程序使用 `os.getcwd()` 所代表的**进程当前工作目录**保存 `settings.json` 和 `rename_tool.log`。按上述方式从 `project/` 目录启动时，这两个文件会生成在 `project/` 内，并由其中的 `.gitignore` 忽略。

配置文件除编号位数设置外，还会保存：
- 主窗口尺寸和位置；
- 重命名预览窗口尺寸和位置；
- 普通批量重命名的目标目录；
- 文件序列插入的目标目录。

旧版配置文件缺少这些字段时，程序会采用默认窗口尺寸和空目录，不影响已有编号位数设置。窗口尺寸在主窗口关闭时保存，预览窗口尺寸在预览窗口关闭时保存；目标目录在主窗口关闭时保存。

当前工作目录不一定是 `.exe` 文件所在目录；从快捷方式启动时，可通过快捷方式的“起始位置”设置工作目录。

## 打包为 Windows EXE

在终端中进入 `project/` 目录后执行：

```bash
cd project
python -m pip install -r requirements.txt
pyinstaller --noconsole --onefile --name 批量文件重命名工具 main.py
```

生成的可执行文件位于 `dist/` 目录。运行时的配置和日志仍写入进程当前工作目录。
